# Passbolt MCP

MCP-сервер для работы с хранилищем паролей Passbolt из AI-ассистента. Позволяет искать записи, создавать и обновлять их, управлять папками и правами доступа. Секрет передаётся настроенному обработчику на стороне сервера; пароли не возвращаются в ответах MCP.

## Что умеет

- Поиск записей по метаданным и выбор записи для конкретного URL.
- Создание и обновление записей, создание папок и выдача доступа в пределах настроенных прав.
- Использование выбранного секрета через зарегистрированный обработчик. Запись и передача секретов по умолчанию отключены и включаются отдельно.

## Установка

Нужны Git, [uv](https://docs.astral.sh/uv/getting-started/installation/) и Python 3.12–3.14.

Установите GnuPG и подготовьте служебную учётную запись Passbolt, её GPG-ключ и пароль к нему, а также политику доступа к хранилищу. Выполните [подготовку Passbolt](INSTALL.md#from-a-clone-or-source-zip) перед командами ниже. Настройщик использует готовые файлы; учётную запись и ключи он не создаёт.

```sh
git clone https://github.com/zai-one/passbolt-mcp.git
cd passbolt-mcp
uv sync --frozen --extra standalone
uv run --frozen --extra standalone python scripts/configure.py
uv run --frozen --extra standalone passbolt-mcp --config mcp.local.json --check-config
uv run --frozen --extra standalone passbolt-mcp --config mcp.local.json
```

Настройщик сохраняет данные только локально. `--check-config` проверяет локальную
конфигурацию без запросов к провайдеру. Последняя команда ждёт подключения MCP-клиента.

Инструкции подключения и установки пакета: [INSTALL.md](INSTALL.md).

## Возможности и ограничения

Новые секреты создаются сервером либо поступают через отдельно подготовленный серверный файл. Инструмента для передачи открытого пароля через MCP в этой версии нет. Подробнее: [работа с секретами и подтверждения](docs/RUNTIME.md).
